# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text, including its enforcement guidelines, applies to
everyone taking part in the project: in issues, pull requests, discussions and any other
project space.

In short: be welcoming and respectful, give and accept constructive feedback gracefully,
and focus on what is best for the community. Harassment, insults, personal or political
attacks, and publishing others' private information are not acceptable.

## Reporting

Report unacceptable behavior to the maintainer, GitHub user
[n-kostadinov](https://github.com/n-kostadinov), or through GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature. Reports are handled confidentially, and the maintainer will act on them following
the Contributor Covenant's enforcement guidelines.
